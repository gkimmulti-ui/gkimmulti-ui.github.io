개인정보처리방침

기기에 저장되는 정보 작품 이름, 캔버스 크기, 픽셀 색상, 작품 식별자와 UI 언어를 앱의 로컬 저장소에 저장합니다. 작품 식별자는 기기에서 생성한 값이며 계정 식별자가 아닙니다. 앱 자체의 추가 암호화는 제공하지 않습니다.

수집·공유 및 권한 개발자는 계정, 작품, 분석 정보 또는 광고 식별자를 서버에 수집하거나 판매하지 않습니다. 로그인, 개발자 서버, 분석 전송, 광고 요청이 없습니다. 미사용 광고 SDK를 제거했고 Android 릴리스의 인터넷·광고 ID·AdServices 권한 제외를 유지했습니다.

저장·공유와 외부 서비스 사용자가 PNG 저장을 선택하면 Android 문서 선택 도구가 지정한 위치에 파일을 기록합니다. 사용자가 공유를 선택하면 PNG를 공유용 캐시에 만들고 선택한 앱에 접근 권한을 부여합니다. 선택한 저장 제공자나 공유 앱이 클라우드 서비스를 사용하면 해당 서비스의 정책이 적용됩니다. 이메일·홈페이지 링크는 외부 앱으로 열며 작품 내용을 자동 첨부하지 않습니다.

보관과 삭제 작품은 사용자가 삭제하거나 앱 데이터가 제거될 때까지 로컬에 보관됩니다. 삭제 확인 후 삭제한 작품은 앱에서 복구하지 못할 수 있습니다. 공유용 캐시와 모든 앱 데이터는 Android의 앱 데이터 삭제 기능으로 제거할 수 있습니다. Android 자동 백업과 기기 간 이전은 이 빌드에서 제외했습니다. 외부에 저장하거나 공유한 PNG는 해당 위치에서 별도로 삭제해야 합니다.

편집 백업 및 복원 JSON 백업에는 작품 이름·크기·픽셀·식별자가 들어가며 사용자가 고른 문서 위치에 저장합니다. 복원은 사용자가 선택한 JSON(최대2MB,100작품)을 검증·미리보기한 뒤 새 식별자로 추가하고 기존 작품을 덮어쓰지 않습니다. 복제도 새 작품으로 추가합니다. 외부 JSON은 외부 위치에서 별도로 삭제하세요. 클라우드 문서 제공자를 고르면 해당 제공자의 정책이 적용됩니다. 약관·개인정보 전문은 각각 오프라인 팝업으로 열립니다.
