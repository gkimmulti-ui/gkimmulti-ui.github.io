이번 주 번호부터, 결과 확인까지.

로또 6/45 번호를 쉽고 재미있게 만들고, 구매한 번호를 회차별로 저장해 당첨 결과까지 확인하는 번호 도우미 앱입니다. 버튼 한 번으로 자동 생성하거나 포함·제외할 번호를 직접 정해 나만의 조합을 만들 수 있고, 한 번에 여러 게임도 생성됩니다. 저장한 번호는 최신 당첨번호와 비교해 일치 개수와 등수를 알려주며, 모든 기록은 기기에 저장됩니다.

  • 자동·조건 번호 생성
  • 회차별 번호 저장
  • 당첨 결과 확인
  • 결과 알림
이용 안내

본 앱이 제공하는 번호는 무작위 생성 또는 사용자가 선택한 조건을 바탕으로 만든 참고용 조합입니다. 특정 번호의 당첨 가능성을 예측하거나 당첨을 보장하지 않습니다. 로또 구매는 개인의 판단과 책임에 따라 적정한 범위에서 이용해 주세요.
