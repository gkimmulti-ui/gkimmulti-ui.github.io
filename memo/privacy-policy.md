# 챙김(Chaengkim) 개인정보처리방침

**최종 개정일 / 시행일: 2026년 6월 27일**

Kenneth App(이하 "개발사")은 모바일 애플리케이션 **챙김**(이하 "앱") 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 앱이 어떤 정보를 수집·이용·보관·보호하는지 설명합니다.

## 1. 수집하는 개인정보 항목

### 가. 이용자가 직접 제공하는 정보
- **Google 계정 정보**: 이름, 이메일 주소, 프로필 사진 (Google 로그인 시)
- **이용자가 앱에 입력한 콘텐츠**: 관리·기록·생활 항목(통신·보험·금융·차량·건강·구독·일정 등), 메모, 알람 일정, 가계부, 비밀번호/계정 보관 항목 등 이용자가 스스로 등록한 모든 정보
- **가족·지인 프로필**: 이름, 관계, 이용자가 입력한 부가 정보
- **사진**: 카메라 촬영 또는 기기 갤러리에서 첨부한 이미지
- **음성 메모**: 이용자가 녹음 기능을 사용하는 경우의 음성 데이터
- **위치 관련 기록**: 주차 위치, 보관함 위치 등 이용자가 직접 입력·기록한 텍스트 정보 (※ 앱은 단말의 GPS 위치를 자동으로 수집하지 않습니다)

### 나. 서비스 이용 과정에서 자동으로 생성·수집되는 정보
- 기기 정보 및 앱 버전, 운영체제 정보 (오류 진단 목적)
- 푸시 알림 토큰 (Firebase Cloud Messaging)
- 광고 식별자(Advertising ID): Google Play 서비스에 의해 생성될 수 있습니다.

## 2. 개인정보의 저장 위치
- **기기 내 저장**: 이용자가 입력한 항목과 사진은 기본적으로 이용자의 단말 내부 저장소에 저장됩니다.
- **클라우드 저장(선택)**: 이용자가 Google 로그인 후 "클라우드 백업"을 실행하면, 입력한 항목 데이터가 **Google Firebase Cloud Firestore**에 이용자 계정과 연결되어 저장됩니다. 백업하지 않으면 데이터는 기기에만 보관됩니다.

## 3. 개인정보의 수집 및 이용 목적
- 회원 식별 및 Google 계정 기반 로그인 제공
- 일정·만료일·납부일 등에 대한 알람 및 푸시 알림 제공
- 이용자 데이터의 클라우드 백업 및 복원, 기기 간 동기화
- 앱 오류 분석 및 기능 개선

## 4. 앱 접근 권한 안내
앱은 아래 권한을 사용하며, 각 기능 사용 시점에 필요한 권한을 요청합니다. 권한 동의를 거부해도 해당 기능을 제외한 나머지 서비스는 이용할 수 있습니다.

| 권한 | 이용 목적 | 필수/선택 |
| --- | --- | --- |
| 알림(POST_NOTIFICATIONS) | 알람 및 일정 푸시 알림 표시 | 선택 |
| 정확한 알람(SCHEDULE_EXACT_ALARM) | 지정한 시각에 정확한 알람 발생 | 선택 |
| 카메라(CAMERA) | 항목에 첨부할 사진 촬영 | 선택 |
| 저장소(사진/미디어) | 갤러리에서 사진 첨부 및 저장 | 선택 |
| 마이크(RECORD_AUDIO) | 음성 메모 녹음 | 선택 |
| 생체 인증(USE_BIOMETRIC/FINGERPRINT) | 앱 잠금 해제 | 선택 |
| 부팅 완료(RECEIVE_BOOT_COMPLETED) | 재부팅 후 예약된 알람 복원 | 선택 |
| 인터넷(INTERNET) | 로그인, 클라우드 백업·복원, 푸시 알림 | 필수 |

## 5. 개인정보의 제3자 제공 및 처리 위탁
개발사는 이용자의 동의 없이 개인정보를 외부에 판매하거나 제공하지 않습니다. 다만 서비스 운영에 필요한 범위에서 아래 사업자의 인프라를 이용(처리 위탁)합니다.

| 수탁 업체 | 위탁 업무 |
| --- | --- |
| Google LLC – Firebase Authentication | Google 계정 기반 로그인 및 인증 |
| Google LLC – Cloud Firestore | 이용자 데이터의 클라우드 저장(백업·복원) |
| Google LLC – Firebase Cloud Messaging | 푸시 알림 발송 |
| Google LLC – Google Play 서비스 | 앱 구동 및 기본 플랫폼 기능 |

위 사업자는 데이터를 해외 서버에 저장·처리할 수 있으며, 각 사업자의 개인정보 보호정책이 함께 적용됩니다. (Google 개인정보처리방침: https://policies.google.com/privacy)

## 6. 법령에 따른 예외적 제공

- 회원 탈퇴(계정 연동 해제) 또는 이용 목적 달성 시, 보관 중인 개인정보는 지체 없이 파기합니다.
- 관련 법령에 따라 보존이 필요한 경우 해당 기간 동안 분리 보관 후 파기합니다.

- 앱 내 설정 화면에서 직접 항목을 수정·삭제하거나 로그아웃할 수 있습니다.
