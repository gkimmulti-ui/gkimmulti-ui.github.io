選択した写真や動画は端末上で分析します。Snap Cleanは内容、サムネイル、ファイル名、写真のメタデータをKenneth Appのサーバーに送信しません。広告サービスが推定する端末の位置情報は写真のメタデータとは別のものです。

無料版はGoogleモバイル広告を使用しています。広告の配信・測定と不正防止のため、SDKがIPアドレス（おおよその地域を推定する場合があります）、アプリや広告への操作、診断情報、該当する場合は端末やアカウントの識別子を処理することがあります。Googleは広告SDKの通信を暗号化します。該当する場合、アプリからGoogleの広告プライバシー設定を利用できます。

Android 1.0.9（10）のプライバシーについて

この案内は、Android 1.0.9（10）が Google Play で提供されてから、そのバージョンにのみ適用されます。旧バージョンには適用されません。

メディア、ファイル名・パス、EXIF、ハッシュ、サムネイル、顔の測定値、埋め込みを当社のサーバーに送信しません。分析は端末上で行います。検索・確認用のメタデータやサムネイルは端末内にキャッシュされることがあります。保存を選んだ別コピーだけをギャラリーに追加します。
Google ML Kitは写真と分析結果を端末上で処理し、Googleのサーバーには送信しません。ただし、処理時間や機能の利用状況などの情報がGoogleに送られたり、モデルや互換性情報の更新のためにGoogleのサーバーへ接続したりする場合があります。これらの情報に写真や分析結果は含まれません。

選んだスクリーンショットの任意の文字認識は端末内で行います。認識した文字を保存したり、文字や画像を開発者に送信したりしません。上記の診断データに関する説明は同様に適用されます。ロシア語は文字認識ではなくファイル名のみを確認します。

アプリに組み込まれた Google ML Kit SDK は、インストールごとの識別子やアプリ・端末・パフォーマンスの情報など、メディアとは無関係の診断・利用データを HTTPS 経由で Google へ送信することがあります。写真や動画の内容、認識した文字列はこれらのデータに含まれません。

Paano ginagamit ang datos sa Android 1.0.7 (8) at 1.0.8 (9)

Sinusuri ng Snap Clean ang mga napili mong larawan at video sa device mo. Hindi ipinapadala sa server ng Kenneth App ang laman ng mga file, thumbnail, pangalan ng file o metadata ng larawan. Iba sa metadata ng larawan ang tinatayang lokasyon ng device na maaaring matukoy ng serbisyong pang-advertising.

Gumagamit ng Google Mobile Ads ang libreng bersyon. Para maghatid at magsukat ng mga ad at maiwasan ang panloloko, maaaring iproseso ng SDK ang IP address (na maaaring magpahiwatig ng tinatayang lugar), paggamit ng app o pakikipag-ugnayan sa ad, datos sa pag-diagnose, at mga ID ng device o account kung naaangkop. Naka-encrypt ang pagpapadala ng datos sa pamamagitan ng SDK. Kung naaangkop, makikita sa app ang mga setting sa privacy ng ad ng Google.

Walang configuration ang mga bersyon sa itaas para paganahin ang Firebase Analytics, Crashlytics o Remote Config. Hindi nangangahulugang gumagana ang mga serbisyong iyon sa mga bersyong ito dahil nabanggit sila sa 12 seksiyon ng naunang patakaran sa ibaba. Google Play ang humahawak sa bayad at mga tala ng transaksiyon ayon sa sarili nitong patakaran. Hindi nabubura ang mga tala na hawak ng Google kapag binura ang data ng app.

Ang 12 seksiyon sa ibaba ay mula sa naunang patakaran. Maaaring mag-iba ang mga feature at serbisyo ayon sa bersyon ng Android app.

Android 1.0.9 (10): update sa privacy

Para lang sa Android 1.0.9 (10) ang bahaging ito, kapag available na ang bersyon sa Google Play. Hindi nito binabago ang patakaran para sa mga naunang bersyon.

Hindi namin ina-upload sa mga server namin ang media, pangalan o path ng file, EXIF, hash, thumbnail, sukat ng mukha o embedding. Sa device ginagawa ang pagsusuri. Maaaring ma-cache sa device ang metadata at thumbnail para sa scan at pagtingin. Hiwalay na kopyang pinili mong i-save lang ang idinadagdag sa gallery.
Sa device mo pinoproseso ng Google ML Kit ang mga larawan at resulta ng pagsusuri. Hindi nito ipinapadala ang mga ito sa server ng Google. Maaari itong magpadala sa Google ng mga sukatan tulad ng tagal ng pagproseso at dalas ng paggamit ng function, at kumonekta para sa mga update sa modelo o compatibility. Hindi kasama sa mga sukatang iyon ang mga larawan o resulta ng pagsusuri.

Ang opsiyonal na pagsusuri ng teksto sa napiling screenshot ay ginagawa sa device. Hindi sine-save ng app ang nakilalang teksto at hindi ito ipinapadala, o ang larawan, sa developer. Umiiral pa rin ang paliwanag sa mga diagnostic ng SDK sa itaas. Para sa Russian, pangalan ng file lang ang sinusuri, walang OCR.

Maaaring magpadala sa Google ang naka-bundle na Google ML Kit SDK, sa pamamagitan ng HTTPS, ng datos sa pag-diagnose at paggamit na hindi media, gaya ng ID ng pag-install at impormasyon tungkol sa app, device o performance. Hindi kasama rito ang nilalaman ng mga larawan o video at ang tekstong nakilala.

Maaaring magpadala sa Google ang naka-bundle na MediaPipe SDK ng impormasyon tungkol sa app at bersyon nito, at ng mga estadistika tungkol sa paggamit ng mga feature, performance at mga error. Hindi nito ipinapadala ang mga larawan o resulta ng pagsusuri.

Kapag naka-configure ang Firebase, maaari itong magpadala ng mga event na walang media, crash diagnostic at impormasyon ng app o device, at kumuha ng mga setting. Kung walang default na Firebase app, walang analytics na ipinapadala at lokal na mga default ang ginagamit. Hindi nakakabit ang larawan o detalye ng file sa mga event.

1

Ang Aming Pangako sa Privacy

Ang Snap Clean ay private by design. Ang lahat ng pagsusuri sa larawan at video — kabilang ang pagtukoy ng duplicate, pagpapangkat ng magkatulad na larawan, pagtukoy ng screenshot, at pagtukoy ng malabong larawan — ay ginaganap nang buo sa iyong device. Wala kaming pinapatakbong server na tumatanggap ng iyong media.

2

Impormasyong HINDI Namin Kinokolekta

Hindi namin kailanman ina-upload, ipinapadala, o iniimbak ang iyong mga larawan, video, thumbnail, pangalan ng file, path ng file, EXIF metadata, data ng lokasyon, data ng mukha, o perceptual/file hash. Hindi kailanman umaalis sa iyong device ang impormasyong ito.

3

Impormasyong Kinokolekta Namin

Gumagamit kami ng Firebase Analytics upang mangolekta ng aggregated, hindi nagpapakilalang mga usage event (halimbawa, na nagsimula ang isang scan o natapos ang isang cleanup) upang matulungan kaming mapahusay ang App. Gumagamit kami ng Firebase Crashlytics upang mangolekta ng crash diagnostics tulad ng stack trace, bersyon ng OS, at bersyon ng app — hindi kailanman ang laman ng larawan o pangalan ng file. Gumagamit kami ng Firebase Remote Config upang maghatid ng mga setting ng feature; hindi ito nangongolekta ng personal na data.

4

Data ng Advertising

Ipinapakita sa mga libreng user ang mga ad sa pamamagitan ng Google AdMob, na maaaring mangolekta ng mga advertising identifier at data ng interaksyon sa ilalim ng sariling patakaran sa privacy ng Google. Maaari kang mag-opt out sa personalized advertising sa pamamagitan ng mga setting ng ad ng iyong device. Inaalis ng Snap Clean PRO ang lahat ng ad.

5

Mga In-App Purchase

Ang mga bayad para sa Snap Clean PRO ay buong pinoproseso ng Google Play o ng Apple App Store. Hindi tumatanggap o nag-iimbak ang Snap Clean ng impormasyon ng iyong payment card.

6

Mga Permission na Hinihiling Namin

Hinihiling ng Snap Clean ang access sa photo library upang i-scan at pamahalaan ang iyong media. Maaari mong ibigay ang buong access, limitadong access, o tanggihan ang access anumang oras sa mga setting ng iyong device; magagamit pa rin ang App kahit limitado ang access.

7

Pagpapanatili ng Data

Ang iyong scan cache, kasaysayan ng paglilinis, at mga setting ay iniimbak lamang nang lokal sa iyong device. Ang pag-uninstall ng App ay nag-aalis sa lokal na datang ito. Pinapanatili ang aggregated analytics data ng Firebase ayon sa mga standard na patakaran nito sa pagpapanatili.

8

Privacy ng mga Bata

Hindi nakatuon ang Snap Clean sa mga batang wala pang 13 taong gulang, at hindi kami sinasadyang nangongolekta ng personal na impormasyon mula sa mga bata.

9

Ang Iyong Mga Karapatan

Dahil hindi kailanman umaalis ang iyong media sa iyong device, walang photo data na maa-access, ma-export, o mabubura namin sa aming mga server. Maaari mong burahin ang lahat ng lokal na data ng app anumang oras sa pamamagitan ng pag-uninstall ng App o pag-clear ng app storage sa mga setting ng iyong device.

10

Mga Serbisyo ng Third-Party

Gumagamit ang Snap Clean ng Google Firebase (Analytics, Crashlytics, Remote Config), Google AdMob, at Google Play Billing / Apple In-App Purchase. Ang paggamit ng data ng bawat provider ay pinamamahalaan ng sarili nitong patakaran sa privacy.

11

Mga Pagbabago sa Patakarang Ito

Maaari naming i-update ang Patakaran sa Privacy na ito paminsan-minsan. Ang patuloy na paggamit ng App matapos magkabisa ang mga pagbabago ay itinuturing na pagtanggap sa binagong patakaran.
